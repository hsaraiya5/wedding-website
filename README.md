# Wedding Website

Source code for our wedding website. 🚧 Work in progress.

Next.js (App Router) + Supabase (Postgres, Auth, Storage), deployed on Vercel. See the [Decision Log](obsidian://) in the Obsidian wedding website project folder for the full history of technical decisions.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.
